Personal Portfolio Website
About the Project
This project is a personal portfolio website created to introduce myself, showcase my skills, and present my projects.

The website is designed with a simple, clean, and responsive layout.

Technologies Used
HTML5: To structure the website.
CSS3: To style the website and make it responsive.
JavaScript: To add interactivity and change the website’s theme.
Features
About Me section.
Skills section.
Projects section.
Contact section.
Interactive background/theme switcher using JavaScript.
Responsive design.
Project Structure
project04/
├── index.html

How to Run
Download or clone the repository.
Open the project folder.
Open index.html in your web browser.
Explore the website and try the theme switcher.
